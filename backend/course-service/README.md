# EnglishForU – English Learning Platform

## Overview

This project was developed as part of the **PIDEV – 4th Year Engineering Program** at **Esprit School of Engineering (Academic Year 2025–2026)**.

EnglishForU is a full-stack web application designed to help students improve their English language skills through interactive lessons, quizzes, and progress tracking.
The platform provides a modern learning experience for students and a management dashboard for teachers and administrators.

---

## Tech Stack

### Frontend

* Angular
* TypeScript
* Bootstrap / Angular Material

### Backend

* Spring Boot (Microservices Architecture)
* Spring Cloud
* REST APIs
* JWT Security

### Database

* PostgreSQL

---

## Architecture

The backend follows a **Microservices Architecture**.

The system is divided into multiple independent services communicating through REST APIs:

* Authentication Service
* User Service
* Course Service
* Quiz Service
* Progress Tracking Service

An API Gateway handles routing and security while each service manages its own database schema.
